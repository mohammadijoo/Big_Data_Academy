Big Data Academy lesson template

Use the published first lesson as the canonical, production-ready layout. This page documents the fields and sections that should be changed when a reserved lesson is implemented.

Canonical source

Copy Chapter01/Lesson1.html into the target reserved lesson path, then update the metadata, navigation state, content, and curriculum status.

Required metadata

  • Unique page title and description
  • Course, chapter, and lesson numbers
  • Lesson title, lead, difficulty, duration, and review date
  • One current sidebar entry and correct previous/next navigation
  • Status changed from planned to published in curriculum.json

Recommended lesson sequence

  1. Learning outcomes
  2. Terminology and system model
  3. Architecture or data-flow explanation
  4. Focused hands-on lab using a free learning path
  5. Operational concerns, tradeoffs, and common mistakes
  6. Checkpoint, practice tasks, summary, and references

Code-window pattern

lesson-placeholder.sql
1SELECT concept, practice, tradeoff
2FROM academy.lesson
3WHERE status = 'published';

Authoring constraints

Keep lessons substantially shorter than the engineering lectures in CaaT Academy. Prefer vendor-neutral explanations, reproducible examples, free or open-source tooling, concise diagrams, and references to primary documentation.
