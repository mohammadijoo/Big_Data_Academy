Course brief

A vendor-neutral foundation before MySQL, PostgreSQL, Hadoop, or Spark.

The curriculum teaches transferable principles first, then uses SQLite for zero-friction practice and compares major SQL dialects where differences matter. Later database courses can therefore focus on their own architecture and operations instead of repeating foundational SQL.

By the end

You will be able to

  • Explain data, databases, DBMSs, SQL, OLTP, and OLAP precisely
  • Design normalized relational schemas with keys and constraints
  • Write portable queries, joins, aggregations, CTEs, and transactions
  • Read execution plans and choose evidence-based indexes
  • Apply security, backup, governance, and migration fundamentals

18 chapters in prerequisite order.
