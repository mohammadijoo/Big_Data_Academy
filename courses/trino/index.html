Course brief

Build a federated SQL platform by connecting SQL semantics to connector capabilities, query plans, data movement, statistics, memory, resource groups, fault tolerance, and governance—then validate performance with explain plans and production telemetry.

A comprehensive Trino course covering federated distributed SQL, catalogs and connectors, lakehouse and relational federation, SQL semantics, query planning, cost-based optimization, pushdown, dynamic filtering, memory and resource governance, fault-tolerant execution, security, observability, Kubernetes operations, plugin development, benchmarking, and production platform design.

This syllabus deliberately separates foundations, data/model semantics, internals, reliability, security, performance, operations, and production design so advanced material is not compressed into generic catch-all chapters.

By the end

You will be able to

  • Write advanced Trino SQL across heterogeneous catalogs using complex types, functions, windows, joins, and lakehouse table formats
  • Explain stages, tasks, splits, pipelines, exchanges, join distribution, statistics, pushdown, dynamic filtering, and adaptive optimization behavior
  • Design and tune secure multi-tenant clusters using resource groups, memory controls, fault-tolerant execution, exchange managers, and workload isolation
  • Operate Trino with TLS and modern authentication, access control, secrets, OpenTelemetry/OpenMetrics/JMX, event listeners, graceful shutdown, and Kubernetes
  • Evaluate connector limitations, benchmark federated workloads, build plugins where necessary, and design a production data-access layer across databases and object storage
