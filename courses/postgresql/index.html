Course brief

From engine fundamentals to advanced production operations.

A deep PostgreSQL curriculum covering SQL, MVCC, indexing, planner internals, VACUUM, WAL, replication, partitioning, JSONB, extensions, security, observability, high availability, logical replication, and production engineering.

This syllabus deliberately separates conceptual foundations, hands-on SQL, engine internals, operational tooling, reliability, security, performance, and capstone work so future lesson generation can go deep without compressing advanced subjects into generic chapters.

By the end

You will be able to

  • Use advanced PostgreSQL SQL and data types including JSONB, arrays, ranges, windows, and recursive queries
  • Reason from MVCC, heap storage, VACUUM, WAL, indexes, and execution plans
  • Design physical/logical replication, partitioning, extensions, RLS, and connection scaling
  • Build evidence-driven observability and performance workflows using PostgreSQL statistics
  • Operate upgrades, PITR, failover, schema change, security, and disaster-recovery runbooks
