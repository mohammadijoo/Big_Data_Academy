Course brief

Engineer NiFi flows by treating queues, back pressure, provenance, state, retries, record schemas, controller services, and cluster placement as first-class architecture—not as drag-and-drop details hidden behind the UI.

A comprehensive Apache NiFi course covering FlowFiles, processors and connections, queues and back pressure, controller services, record-oriented processing, routing and transformation, HTTP/database/files/messaging integration, provenance, parameterization, clustering, Site-to-Site, NiFi Registry/versioning, MiNiFi, security, observability, performance, upgrades, and production flow design.

This syllabus deliberately separates foundations, data/model semantics, internals, reliability, security, performance, operations, and production design so advanced material is not compressed into generic catch-all chapters.

By the end

You will be able to

  • Build maintainable NiFi 2.10 dataflows using processors, FlowFiles, relationships, controller services, parameter contexts, record readers/writers, and reusable process groups
  • Design safe routing, transformation, batching, prioritization, back pressure, retry, dead-letter, idempotency, and provenance strategies for heterogeneous systems
  • Integrate files, object stores, databases, APIs, Kafka/messaging, CDC-style streams, and edge agents while understanding transaction and delivery boundaries
  • Secure and operate clustered NiFi using TLS, identity providers, authorization, Site-to-Site, state management, observability, capacity planning, and disaster recovery
  • Version, test, promote, upgrade, troubleshoot, and benchmark production flows with explicit runbooks instead of relying on UI-only manual operations
