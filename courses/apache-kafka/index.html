Course brief

Operate Kafka by reasoning from the replicated log upward: partitions, leaders, acknowledgements, consumer positions, group protocols, retention, transactions, storage, controllers, and failure recovery—then validate guarantees under load and fault injection.

A comprehensive Apache Kafka course covering event-streaming architecture, KRaft, topics and partitions, producers, consumers, groups and Share Groups, offsets, replication, retention and compaction, delivery semantics, transactions, tiered storage, security, quotas, Kafka Streams, MirrorMaker, observability, upgrades, capacity planning, and production reliability.

This syllabus deliberately separates foundations, data/model semantics, internals, reliability, security, performance, operations, and production design so advanced material is not compressed into generic catch-all chapters.

By the end

You will be able to

  • Design topic/partition strategies and implement reliable producers, consumers, consumer groups, Share Groups, offset handling, retries, and ordering guarantees
  • Explain KRaft metadata quorums, replication, ISR, leader election, storage segments, retention, compaction, transactions, and failure boundaries
  • Secure and govern Kafka using TLS, SASL, OAuth/SCRAM/Kerberos concepts, ACLs, quotas, multi-tenancy, and least-privilege operational procedures
  • Build stateful Kafka Streams applications and cross-cluster replication architectures while understanding exactly-once boundaries and recovery behavior
  • Capacity-plan, benchmark, observe, upgrade, troubleshoot, and recover production Kafka clusters using metrics and explicit SLOs rather than defaults
