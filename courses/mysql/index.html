Course brief

From engine fundamentals to advanced production operations.

A complete MySQL path from installation and SQL fundamentals through InnoDB internals, indexing, optimizer behavior, replication, Group Replication, security, backup, observability, upgrades, and production architecture.

This syllabus deliberately separates conceptual foundations, hands-on SQL, engine internals, operational tooling, reliability, security, performance, and capstone work so future lesson generation can go deep without compressing advanced subjects into generic chapters.

By the end

You will be able to

  • Model and query MySQL databases with correct transactional semantics and indexing
  • Explain InnoDB storage, MVCC, redo/undo, locking, and optimizer evidence
  • Design replication or InnoDB Cluster high availability and safe failover
  • Secure, back up, restore, observe, tune, upgrade, and troubleshoot production MySQL
  • Integrate MySQL with applications using reliable pooling, migrations, retries, and deployment patterns
