Course brief

Build CDC systems by understanding the source database log first: what is captured, where offsets live, how snapshots transition into streaming, how schema changes are represented, and exactly where duplicates, gaps, reordering, and operational risk can occur.

A comprehensive Debezium course covering change-data capture fundamentals, database logs, snapshots and streaming, event envelopes, schema history, offsets, signals, incremental snapshots, Kafka Connect, Debezium Server and Engine, source connectors, sinks, transformations, outbox patterns, OpenLineage, security, observability, upgrades, and production CDC architecture.

This syllabus deliberately separates foundations, data/model semantics, internals, reliability, security, performance, operations, and production design so advanced material is not compressed into generic catch-all chapters.

By the end

You will be able to

  • Configure and operate Debezium 3.6 source connectors across major relational/document systems while understanding the database-specific log prerequisites
  • Explain initial/incremental snapshots, offsets, schema history, heartbeats, transaction metadata, signals, ordering, tombstones, and event-envelope semantics
  • Deploy Debezium through Kafka Connect, Debezium Server, Embedded Engine, Quarkus extensions, and Platform/CLI patterns with secure configuration
  • Design reliable consumers, sinks, outbox pipelines, schema-evolution handling, lineage, filtering/routing SMTs, replay, and disaster-recovery procedures
  • Diagnose lag, connector failures, log-retention hazards, schema-history problems, source load, duplicates, and upgrade risks using metrics and controlled failure drills
