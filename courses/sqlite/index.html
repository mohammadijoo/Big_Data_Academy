Course brief

Learn the complete lifecycle of an embedded relational database.

SQLite is more than a database file and a few SQL statements. This course develops engine-specific judgment about types, constraints, transactions, locking, WAL, pages and B-trees, planner evidence, virtual tables, drivers, migrations, backup and recovery, performance, security, deployment, and production operations.

By the end

You will be able to

  • Use SQLite files and the sqlite3 shell confidently, with deliberate schemas, types, keys, and constraints
  • Design reliable transactions, concurrency policies, WAL workflows, busy handling, and checkpoints
  • Measure query plans, indexes, storage behavior, JSON, FTS5, R-Tree, and performance changes with evidence
  • Embed SQLite safely in applications using bound parameters, explicit connection initialization, and versioned migrations
  • Back up, restore, test, secure, troubleshoot, operate, and defend a production SQLite architecture—and recognize when to migrate away
