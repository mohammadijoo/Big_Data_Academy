Course brief

Turn an ORM into a predictable data-access layer, not a black box.

A complete Entity Framework Core path from DbContext and model mapping through LINQ translation, change tracking, migrations, concurrency, transactions, provider-specific behavior, diagnostics, testing, security, multi-tenancy, performance, and production architecture.

This syllabus deliberately separates foundations, data modeling, query behavior, internals, reliability, security, performance, operations, and production design so advanced material is not compressed into generic catch-all chapters.

By the end

You will be able to

  • Design precise EF Core models using conventions, Fluent API, relationships, complex types, conversions, inheritance, and provider-aware mappings
  • Write LINQ that translates predictably, choose loading and tracking strategies deliberately, and diagnose generated SQL
  • Manage schema evolution with migrations, reverse engineering, seeding, deployment scripts, and compatibility controls
  • Handle concurrency, transactions, retries, multi-tenancy, security, testing, and observability without hiding database semantics
  • Tune and operate EF Core in production using projections, batching, pooling, compiled artifacts, interceptors, provider-specific features, and evidence-based performance work
