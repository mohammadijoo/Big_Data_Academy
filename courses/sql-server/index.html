Course brief

From engine fundamentals to advanced production operations.

A production-focused SQL Server curriculum covering T-SQL, storage engine internals, indexing, Query Store, intelligent query processing, security, backup/recovery, Availability Groups, replication, columnstore, in-memory OLTP, observability, and SQL Server 2025 capabilities.

This syllabus deliberately separates conceptual foundations, hands-on SQL, engine internals, operational tooling, reliability, security, performance, and capstone work so future lesson generation can go deep without compressing advanced subjects into generic chapters.

By the end

You will be able to

  • Write production T-SQL and reason about storage, transactions, tempdb, indexes, and plans
  • Use Query Store, statistics, DMVs, wait analysis, and Extended Events for diagnosis
  • Design backup/PITR, Availability Groups, replication, and DR with explicit RPO/RTO
  • Apply SQL Server security, encryption, auditing, Agent automation, and integrity checks
  • Evaluate columnstore, In-Memory OLTP, vector/AI features, upgrades, and hybrid deployment choices
