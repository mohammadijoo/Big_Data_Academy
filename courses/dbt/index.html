Course brief

Build trustworthy transformation projects by making SQL dependency graphs, model contracts, tests, source freshness, incremental state, documentation, deployment environments, and change control explicit—then treat the warehouse and adapter as part of the execution model rather than hiding them behind dbt.

A comprehensive dbt Core course covering analytics engineering, project structure, models and ref/source graphs, materializations, incremental and microbatch processing, tests, snapshots, seeds, macros/Jinja, packages, documentation, contracts, model versions, state/defer, artifacts, adapters, CI/CD, security, performance, governance, semantic-layer awareness, and dbt Core 2.0/Fusion migration planning.

This syllabus deliberately separates foundations, data/model semantics, internals, reliability, security, performance, operations, and production design so advanced material is not compressed into generic catch-all chapters.

By the end

You will be able to

  • Build modular dbt projects with sources, staging/intermediate/mart layers, ref/source dependencies, reusable macros, packages, tests, documentation, and explicit contracts
  • Choose and tune view/table/incremental/ephemeral/custom materializations including merge, insert-overwrite, microbatch, partitioning, clustering, and warehouse-specific behavior
  • Use snapshots, freshness, state selection, defer, slim CI, model versions, access rules, exposures/metrics awareness, and artifacts to govern change safely
  • Debug compilation and runtime behavior using manifests, run results, compiled SQL, logs, query plans, adapter behavior, warehouse metrics, and deterministic test data
  • Operate dbt Core in CI/CD and production with secrets, environment promotion, orchestration, package pinning, migration gates, and a clear path from 1.11 to future 2.0/Fusion capabilities
