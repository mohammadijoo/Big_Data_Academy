Course brief

Use Redis as a deliberate data-structure server, not merely “a cache.”

A complete Redis path covering core and advanced data types, expiration, streams, JSON, Search, vector sets, probabilistic and time-series structures, transactions, functions, pipelining, Pub/Sub, persistence, memory/eviction, replication, Sentinel, Cluster, ACL/TLS security, application patterns, observability, performance, backup, upgrades, and production operations.

This syllabus deliberately separates foundations, data modeling, query behavior, internals, reliability, security, performance, operations, and production design so advanced material is not compressed into generic catch-all chapters.

By the end

You will be able to

  • Choose Redis data structures from operation complexity, cardinality, memory cost, persistence needs, and access patterns
  • Build reliable caching, counters, queues, streams, messaging, search, vector, geospatial, probabilistic, and time-series workflows
  • Reason about atomicity, scripting/functions, pipelining, client behavior, expiration, eviction, persistence, replication, Sentinel, and Cluster
  • Secure and observe Redis with ACLs, TLS, metrics, slow/latency analysis, memory diagnostics, benchmarks, backups, and tested upgrades
  • Design production Redis architectures that control hot keys, stampedes, locks, idempotency, failover, capacity, and disaster recovery
