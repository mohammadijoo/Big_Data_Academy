Course brief

Design client-facing document applications safely, then understand the serverless scaling, query, security, recovery, observability, and cost mechanics behind Firestore.

A complete Firebase/Cloud Firestore course covering Standard and Enterprise editions, Native Core and Pipeline operations, document modeling, SDKs, realtime listeners, offline persistence, queries and indexes, transactions, Security Rules, IAM/App Check, scaling and hotspots, aggregations, vector search, MongoDB compatibility, TTL, backups/PITR, encryption/networking, observability, cost engineering, migration, and production architecture.

This syllabus deliberately separates foundations, modeling, querying, internals, reliability, security, performance, operations, and production design so advanced material is not compressed into generic catch-all chapters.

By the end

You will be able to

  • Model Firestore documents/collections/subcollections for access patterns, limits, atomicity, lifecycle, and scale
  • Use Core queries, indexes, listeners, offline persistence, transactions, batched writes, aggregations, and vector search correctly
  • Secure mobile/web access with Authentication, Security Rules and App Check while separating trusted server IAM paths
  • Understand Enterprise Native Pipeline operations and MongoDB compatibility without assuming identical behavior to Standard Native mode or MongoDB
  • Operate Firestore with backups/PITR, TTL, CMEK/network controls, Query Explain/Insights, quotas, cost models, testing, and production runbooks
